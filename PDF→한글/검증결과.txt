검증 결과 (2026-10-01)

기존 PDF분할: 28개 테스트 통과.
PDF→한글: 11개 테스트 통과.
- 실제 한글 문장/표 PDF→DOCX 글자 보존 및 편집 가능한 표
- 실제 이미지 스캔 PDF의 한국어 OCR 및 격자 표 복원
- 원문+스캔 혼합 PDF
- 손상/암호 PDF 실패 처리
- OCR 학습 데이터 SHA-256 검사
- 완료 기록/중복 생략/HWP 삭제 후 재생성 (HWP 저장은 모의 객체)
- HWP 실패 시 DOCX 보관 및 미완료 표시
- 2018/2022 공통 COM 호출 계약 (두 버전 값을 가진 모의 객체)

추가: 두 입력 파일의 실제 PDF/DOCX 변환 + 모의 HWP 저장을 폴더 감시 루프로 확인.
Python 문법 / BAT CRLF / VBS UTF-16 확인.
Windows x64 Python 3.12용 라이브러리 휠과 pywin32 다운로드 가능 여부 확인.

테스트 환경: macOS. 새 변환기 Python 3.14 / PyMuPDF 1.28.2 / pdf2docx 0.5.13.
Windows 한글 2018/2022 실행, COM/DLL 등록, 최종 HWP 레이아웃은 실제 검증하지 못했습니다.
따라서 호환성 보장이나 OCR 100% 정답률을 의미하지 않습니다.
설치된 PC에서 'PDF→한글/한글 호환성 점검.bat'으로 실제 저장/다시 열기를 확인하세요.

회귀 검증 3개 추가: insert:true 필수 경로, 자동 인식 재시도 전 문서 초기화, 두 시도 실패 시 성공 처리 방지.
Windows 실기 검증은 별도로 필요합니다.
