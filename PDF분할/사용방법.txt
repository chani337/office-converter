기존 Office→PDF 변환 지원 복구
'변환할 파일' 폴더에 아래 문서를 모두 넣을 수 있습니다.
- 한글: HWP / HWPX → 한컴 한글로 PDF 변환
- Word: DOC / DOCX / RTF / ODT → Microsoft Word로 PDF 변환
- PowerPoint: PPT / PPTX → Microsoft PowerPoint로 PDF 변환
- Excel: XLS / XLSX → Microsoft Excel로 PDF 변환
- PDF: 전체 PDF 복사 + 페이지별 분할

예: 변환할 파일\발표.pptx
 → PDF 변환 완료\전체 PDF\발표.pptx\발표.pdf
 → PDF 변환 완료\페이지별 PDF\발표.pptx\발표_001.pdf ...
 → PDF 변환 완료\페이지별 JPG\발표.pptx\발표_001.jpg ...

Windows에 변환할 형식의 데스크톱 프로그램이 설치되어 있어야 합니다.
Office 웹 버전만 설치/사용 중인 환경에서는 COM 변환이 되지 않습니다.
Excel의 PDF 페이지 수는 문서의 인쇄 영역과 페이지 설정에 따릅니다.
기존 백그라운드 시작/종료, 로그인 자동 시작 기능을 그대로 사용합니다.

창 없이 자동 감시하기
1. 새 ZIP을 Windows에 전체 압축 해제하고 설치.bat을 처음 한 번 실행하세요.
2. 백그라운드 시작.vbs를 더블클릭하세요.
3. 시작 안내를 닫아도 감시는 계속됩니다. 변환할 파일 폴더에 파일을 넣으세요.

백그라운드 종료.vbs: 현재 파일을 마친 후 종료 요청
상태 확인.vbs: 실행/종료 대기 여부 확인
로그인 자동시작 등록.vbs: 다음 Windows 로그인부터 창 없이 시작 (선택)
로그인 자동시작 해제.vbs: 다음 로그인부터 자동 시작 해제

- 명령프롬프트와 변환용 한글 창은 숨깁니다. 프로그램의 특수 확인창은 나타날 수 있습니다.
- 같은 폴더에서 두 번 시작해도 중복으로 감시하지 않습니다.
- 실행기록.log: 변환 내역 / 백그라운드오류.log: 백그라운드 시작·실행 오류
- 로그인 자동시작은 현재 사용자 Startup 폴더에 PDFSplitBackground.lnk를 등록합니다.
  등록 위치를 옮기면 다시 등록하세요. 여러 설치 폴더 중 마지막으로 등록한 하나를 사용합니다.
- 자동시작 해제는 현재 실행을 종료하지 않습니다. 종료 버튼은 별도로 누르세요.
- PC가 켜져 있고 로그인한 동안 동작합니다. 절전 중에는 멈추고 복귀 후 다시 감지합니다.
- Windows 서비스가 아니므로 로그아웃/종료 시 중지됩니다.
- 백그라운드 실행 중 설치/복구하려면 먼저 종료하고 상태 확인 후 설치하세요.
- VBS 실행이 회사 정책으로 차단된 PC에서는 실행.bat을 사용하세요.

PDF분할 — 전체 PDF + JPG + 1페이지 PDF 자동 저장 (안정화 버전)

시작 방법
1. 기존 실행 창을 닫으세요.
2. 새 ZIP을 Windows의 짧은 로컬 경로에 전체 압축 해제하세요.
   예: C:\PDF분할 (ZIP 안에서 바로 실행하지 마세요.)
3. '실행.bat'을 더블클릭하세요.
   처음에는 필요한 라이브러리를 자동 설치하고, 이후에는 바로 실행합니다.
4. '변환할 파일'에 한글 / Word / PowerPoint / Excel / PDF 파일을 넣으세요.
5. 실행 창을 켜 두면 자동으로 처리합니다. 종료: Ctrl+C.

폴더 구조
PDF분할
  실행.bat              자동 설치 + 감시 시작
  한번만 변환.bat       현재 파일만 처리하고 종료
  설치.bat              설치/의존성 복구만 실행 (선택)
  변환할 파일              여기에 원본 넣기
  PDF 변환 완료
    전체 PDF
      보고서.hwp
        보고서.pdf            전체 페이지를 담은 PDF 1개
    페이지별 JPG
      보고서.hwp
        보고서_001.jpg
        보고서_002.jpg
    페이지별 PDF
      보고서.hwp
        보고서_001.pdf
        보고서_002.pdf

필요한 환경
- Windows, Python 3.10 이상 (3.12 또는 3.13 권장)
- HWP/HWPX: 데스크톱 한컴 한글 설치 및 최초 실행 완료
- PDF 입력만 처리할 때에는 한글이 없어도 됩니다.
- 최초 설치/복구 때만 인터넷 연결이 필요합니다.
- Python이 없으면 실행 창에 안내가 나옵니다.
  https://www.python.org/downloads/windows/
  설치 시 'Add python.exe to PATH' 선택 후 실행.bat을 다시 실행하세요.
- 한글 보안 DLL은 기존 PDFLocal에서 사용하던 32비트 DLL입니다.
  현재 PC의 한글 버전과 호환되어야 합니다. 보안 모듈 오류는 실행기록에 표시됩니다.

처리 방식
- 원본은 보존합니다. 전체 PDF는 모든 페이지를 담은 1개 파일입니다.
- 페이지별 JPG와 페이지별 PDF는 각각 페이지당 파일 하나입니다.
- 한글→PDF 변환은 한 번만 실행하고, 같은 PDF에서 세 종류 결과를 만듭니다.
- PDF 입력은 원래 PDF를 전체 PDF 폴더에 그대로 복사합니다.
- 세 종류 결과 중 하나가 없거나 0바이트이면 새 번호 폴더로 다시 생성합니다.
- JPG 기본값: 200 DPI, 품질 95. PDF는 원본 페이지를 직접 복사합니다.
- PDF를 이미지로 바꿔서 다시 PDF로 만드는 방식이 아닙니다.
- 각 PDF의 텍스트/페이지 크기/회전을 유지합니다.
  원래 다른 페이지로 이동하던 내부 링크는 분할 후 유지되지 않을 수 있습니다.
- 하위 폴더도 처리하며, 같은 이름의 파일은 하위 폴더별로 분리합니다.
- 변경 없는 완료 파일은 건너뜁니다. 결과가 없거나 0바이트면 새 번호 폴더에 재생성합니다.
- .complete.json은 완료 기록입니다. 삭제하지 마세요.
- 기존 결과를 덮어쓰지 않습니다. 내용 변경 시 '(1)', '(2)' 폴더를 추가합니다.
- 파일 크기와 수정 시간이 3초간 안정된 뒤 처리합니다.
- 자동 감시에서는 실패한 파일을 30초 간격으로 최대 3회 시도합니다.
  실패 원인 해결 후 원본을 수정하거나 실행 창을 닫고 다시 실행하세요.
- 한번만 변환은 시작 당시 파일만 처리하며, 실패 파일을 반복 재시도하지 않습니다.
- 기존 PDFLocal처럼 변환용 한글 창을 숨깁니다. 변환 실패/시간 초과는 실행기록.log에서 확인하세요.
- 문서 변환이 5분 이상 응답하지 않으면 해당 작업과 동일 프로그램의 후속 변환을 중지합니다.
  다른 프로그램 형식과 PDF 입력은 계속 처리합니다. 남아 있는 확인창을 정리하고 재실행하세요.
  다른 한글 프로세스를 일괄 강제 종료하지 않습니다.
- 파일을 쓰는 중 오류가 나면 불완전한 결과를 완료로 기록하지 않습니다.
  전원 차단/강제 종료 때 남은 '.작업-' 폴더나 PDF만 있는 폴더는 보존되며,
  다음 실행에서 새 번호 폴더로 다시 처리할 수 있습니다.

문제가 생겼을 때
- 변환 오류: 실행기록.log (용량이 커지면 최대 2개 이전 기록 보관)
- 시작/설치 오류 요약: 설치기록.log, 자세한 pip 오류: 실행 창
- '이미 실행 중': 기존 실행 창을 확인하세요. 두 번 켜지지 않도록 차단합니다.
- 경로가 너무 길다: 프로그램을 C:\PDF분할 같은 짧은 경로로 옮기고 파일명을 줄이세요.
- 암호 PDF/암호 한글: 일반 문서로 저장한 사본을 입력하세요.
- 다른 PC로 옮길 때 '.venv'는 복사하지 마세요. 새 ZIP으로 설치하세요.

고급 설정 (이 폴더의 명령 프롬프트)
.venv\Scripts\python.exe split.py --dpi 300 --timeout 600
DPI 72~600, 문서 변환 대기 한도 10~3600초.

검증 범위
macOS에서 실제 PDF/JPG 처리와 자동화 테스트를 수행했습니다.
Windows 배치 실행, DLL 등록, 실제 한글 COM 변환은 이 환경에서 실행 검증할 수 없습니다.
기존 PDFLocal 파일과 설정은 수정하지 않습니다.

이번 버전은 전체 PDF / 페이지별 PDF / 페이지별 JPG 폴더를 사용합니다.
이전 버전의 JPG / PDF 폴더에 있던 결과는 변경하지 않습니다.
